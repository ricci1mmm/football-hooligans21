# WORLD MAP

## Город

### Север
Старые панельки, дворы, граффити, ультрас.

### Центр
Кафе, магазины, полиция, городская жизнь.

### Промзона
Гаражи, заводы, склады, подпольные активности.

### Юг
Частный сектор, автомастерские, бар.

### Порт
Редкие товары, рынок, особые события.

Каждый район имеет:
- визуальный стиль
- NPC
- задания
- музыку
- влияние фирм
- случайные события
