# ART STYLE

Название стиля: Urban Cartoon Noir

## Цвета

- графитовый фон
- зеленый газон
- красные файеры
- оранжевые фонари
- желтый городской свет
- белые контуры

## Объекты

Единый стиль для:
- персонажей
- зданий
- машин
- предметов
- интерфейса
- карт

## Интерфейс

Не сайт с кнопками, а игровые панели с иллюстрациями.
Каждая локация должна выглядеть как отдельная сцена мультфильма.
